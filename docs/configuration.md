# Configuração — moodle-tool_brcli

## Requisitos de Execução

- Acesso via Shell/SSH ao servidor com permissões de usuário web (`www-data` ou equivalente).
- PHP CLI configurado no PATH do sistema.

## Scripts Disponíveis

- `admin/tool/brcli/backup.php`: Script de execução de backup em lote.
- `admin/tool/brcli/restore.php`: Script de restauração em lote.
